# Palimpsest — Помощник по лекциям

## Исходная задача
> «Я собираюсь делать ИИ агента который будет мне помогать с лекциями в универе на английском, думаю сделать такую систему: записывает лекции с ноутбука — записывает все в папку с исходным текстом, потом делает мне конспект и после конспекта тест на его знание».

## Пользовательские выборы
- Запись: и микрофон, и загрузка файлов.
- Транскрипция: Web Speech API (браузерная, бесплатная).
- LLM: DeepSeek (пользователь получит ключ позже; пока замокано).
- Формат теста: смесь MCQ + True/False + Короткий ответ.
- Язык интерфейса: русский. Лекции в исходнике на английском, конспекты и вопросы на русском.

## Персона
- Русскоязычный студент университета, слушает лекции на английском, нужен быстрый конспект + самопроверка.

## Архитектура
- **Backend** FastAPI + MongoDB (`/app/backend/server.py`).
  - Raw-транскрипт также пишется в файл `/app/backend/lecture_transcripts/{id}_{title}.txt`.
  - LLM через `emergentintegrations.LlmChat` -> Gemini 3 Flash (дёшево). Есть переключатель: если появится `DEEPSEEK_API_KEY` в `.env`, использовать его (заготовка на будущее).
- **Frontend** React + Tailwind + shadcn/ui (`/app/frontend/src`).
  - Страницы: `Dashboard`, `RecordPage`, `LibraryPage`, `LecturePage`, `TestPage`.
  - Хук `useSpeechRecognition` — live-транскрипция через Web Speech API.

## Реализовано (2026-02-05) — Итерация 5: Auth + Freeze Streak
- **Регистрация и вход по email/паролю** — bcrypt-хэш + JWT в httpOnly cookies (24h access + 30d refresh). Endpoints: `/api/auth/register`, `/login`, `/logout`, `/me`, `/refresh`. Валидация Pydantic + EmailStr, минимальная длина пароля 6.
- **Полная изоляция данных**: каждый документ (`lectures`, `tests`, `attempts`, `review_items`, `review_days`) содержит `user_id`. Все endpoints фильтруют по `current_user.id`. Каскадные удаления по `lecture_id + user_id`.
- **Admin-сид**: при старте бэкенд создаёт `admin@upsidestudy.app / admin1234` (из `ADMIN_EMAIL/ADMIN_PASSWORD`) и мигрирует все legacy-документы (без `user_id`) под этого админа.
- **Freeze Streak**: `POST /api/streak/freeze` добавляет сегодняшнюю дату в `user.freeze_dates`. Правило: одна заморозка на скользящую неделю. `_compute_streak()` учитывает `freeze_set` — если день пропущен, но покрыт заморозкой в пределах последних 3 дней, серия продолжает считаться. `/api/stats` возвращает `can_freeze`, `next_freeze_in_days`, `freeze_dates`. Кнопка `Снежинка + Заморозить на 2 дня` на карточке серии.
- **QR-запись с телефона под auth**: `POST /api/lectures/{id}/record-token` (auth) возвращает JWT (24h, scope `record`). QR-URL `/m/{id}?t={token}`. PATCH transcript теперь принимает либо user-cookie, либо record-token из `Authorization: Bearer`. Мобильная страница получает данные лекции через `/api/lectures/{id}/mobile?t={token}`.
- **Frontend**: `AuthProvider`, `ProtectedRoute`, страница `AuthPage` (login/register в одной), navigation `/login` при 401. `axios.withCredentials = true`.
- Пофиксы (по итерации 4 testing_agent — backend 97% / frontend 95%):
  - `access_token` больше не возвращается в body login/register (cookies only).
  - `POST /api/digest/send` использует `DIGEST_EMAIL` как fallback для тестового режима Resend, чтобы кнопка «Отправить себе» работала для любого пользователя.
  - Каскадные удаления лекций скопированы по `user_id`.
  - Улучшен контраст disabled-кнопки заморозки на карточке серии.
  - `/api/config` вернул `digest_email_fallback` для показа в UI.

## Реализовано (2026-02-04) — Итерация 4
- **Streak Counter 🔥**: новая коллекция `review_days` (upsert `{day: YYYY-MM-DD}` при каждом ответе в повторении). `/api/stats` возвращает `streak` (последовательные дни, начиная от сегодня или вчера — grace-period 1 день) и `reviewed_today`. На дашборде большая карточка с анимированным пламенем `Flame` из lucide (свечение + мерцание через `flame-flicker` keyframes), бейджиком со счётчиком дней и мотивационным подзаголовком ("Сегодня уже занимались — серия не сгорит" / "Ещё не занимались сегодня — не потеряйте серию"). Кликается — ведёт на страницу повторения.
- **Auto Glossary**: `_build_glossary()` вынесен в общий хелпер и автоматически вызывается сразу после `POST /api/lectures/{id}/summary`. Ошибка глоссария не роняет генерацию конспекта, только логируется. Toast на клиенте сообщает `Конспект готов · глоссарий (N)`.

## Реализовано (2026-02-03) — Итерация 3 (upsidestudy)
- Приложение переименовано в **upsidestudy** (заголовок сайдбара, письмо дайджеста, mobile-хедер).
- **DeepSeek**: обновлён ключ, баланс пополнен — конспект и тест теперь идут напрямую через DeepSeek.
- **Глоссарий**: `POST /api/lectures/{id}/glossary` — LLM извлекает 8–15 английских терминов + перевод + определение на русском. UI: кнопка «Глоссарий» на странице лекции, карточки внизу, а в самом транскрипте термины подсвечены пунктирной линией — клик открывает поповер с переводом и определением. Плюс `GET /api/glossary/all` — сводный глоссарий.
- **Weekly Digest (Resend)**: `POST /api/digest/send` шлёт красивое HTML-письмо (стилизованное под Botanical Brutalism) с новыми лекциями за неделю и числом карточек к повторению. `GET /api/digest/preview` — предпросмотр в UI. **APScheduler**: воскресенье 20:00 UTC → авто-отправка на `workspace67676752@gmail.com`. Первое тестовое письмо доставлено успешно.
- **QR-запись с телефона**: новый режим "Телефон (QR)" на странице записи. Создаёт лекцию, показывает QR со ссылкой на `/m/{lecture_id}`. Мобильная страница ведёт Web Speech API, каждые ~4 секунды PATCH-ит транскрипт (`append=true`). Десктоп polls каждые 3 секунды и показывает растущий транскрипт в реальном времени.
- **Тёмная / светлая тема**: переключатель в сайдбаре (Sun/Moon), сохраняется в `localStorage`, применяется и на `/m/:id` тоже. Все цвета через CSS-переменные с `[data-theme="dark"]` override.
- **Улучшенный шрифт**: заменил Cormorant Garamond на **Fraunces** (variable-serif, теплее и лучше читается), базовый размер тела текста поднят до 15/17 px с увеличенным line-height.
- Пофиксы после testing_agent: `MobileRecordPage` показывает состояние "Лекция не найдена" вместо повторяющегося toast; `POST /api/digest/send` работает без тела запроса; тема применяется во всём приложении (включая мобильную страницу).
