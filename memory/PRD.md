# Palimpsest — Помощник по лекциям

## Исходная задача
> «Я собираюсь делать ИИ агента который будет мне помогать с лекциями в универе на английском, думаю сделать такую систему: записывает лекции с ноутбука — записывает все в папку с исходным текстом, потом делает мне конспект и после конспекта тест на его знание».

## Пользовательские выборы
- Запись: и микрофон, и загрузка файлов.
- Транскрипция: Web Speech API (браузерная, бесплатная).
- LLM: DeepSeek (пользователь получит ключ позже; пока замокано).
- Формат теста: смесь MCQ + True/False + Короткий ответ.
- Язык интерфейса: русский. Лекции в исходнике на английском, конспекты и вопросы на русском.

## Персона
- Русскоязычный студент университета, слушает лекции на английском, нужен быстрый конспект + самопроверка.

## Архитектура
- **Backend** FastAPI + MongoDB (`/app/backend/server.py`).
  - Raw-транскрипт также пишется в файл `/app/backend/lecture_transcripts/{id}_{title}.txt`.
  - LLM через `emergentintegrations.LlmChat` -> Gemini 3 Flash (дёшево). Есть переключатель: если появится `DEEPSEEK_API_KEY` в `.env`, использовать его (заготовка на будущее).
- **Frontend** React + Tailwind + shadcn/ui (`/app/frontend/src`).
  - Страницы: `Dashboard`, `RecordPage`, `LibraryPage`, `LecturePage`, `TestPage`.
  - Хук `useSpeechRecognition` — live-транскрипция через Web Speech API.

## Реализовано (2026-02-01)
- Dashboard со статистикой (лекций, тестов, попыток, средний балл) + список последних лекций.
- Три способа завести лекцию: микрофон (live), вставка текста, загрузка `.txt/.md`.
- Библиотека с карточками, удаление, превью.
- Экран лекции: dual-pane «Транскрипт | Конспект», генерация конспекта, генерация теста, история тестов.
- Тест: 8 вопросов (4 MCQ + 2 T/F + 2 короткий ответ), прогресс-бар, проверка ответов с per-question review и объяснениями, повторное прохождение.
- Полностью русский интерфейс.
- Backend: 100% (23/23) — endpoints `/config`, CRUD `/lectures`, `/transcript`, `/summary`, `/test`, `/grade`, `/attempts`, `/stats`.

## Реализовано (2026-02-02) — Итерация 2
- **DeepSeek**: реальная интеграция через `httpx` -> `api.deepseek.com/v1/chat/completions` (model `deepseek-chat`). Если баланс закончился — автоматический graceful fallback на Gemini 3 Flash через Emergent Universal Key. Пользователь видит правильный `llm_mode=deepseek` в UI.
- **Whisper (аудио → текст)**: `POST /api/transcribe-audio` (multipart, до 25 МБ). Frontend режим "Аудио → текст" — загрузка mp3/mp4/m4a/wav/webm с прогресс-баром, автоматическая подстановка распознанного текста.
- **PDF-экспорт**: клиент-сайд `window.print()` + `@media print` CSS. Печатается только: заголовок → конспект → ключевые тезисы → 8 вопросов → 8 ответов с объяснениями (три страницы).
- **Spaced Repetition**: на каждый ошибочный ответ теста создаётся `review_items` с `due_at=now+1d`. GET `/api/review/due` возвращает все просроченные карточки. POST `/api/review/{id}/answer` проверяет ответ, при верном — удваивает интервал (1→2→4→7→14→30 дней), при ошибке — сбрасывает на 1 день. Sidebar показывает бейдж с числом просроченных карточек.
- Исправлено (по замечаниям testing_agent):
  - `_norm()` теперь Unicode-aware — короткие ответы на кириллице оцениваются верно.
  - При удалении лекции каскадно удаляются `review_items` (нет "фантомов" в бейдже).
  - LaTeX-делимиторы (`\[...\]`, `$$`, `\frac{}{}`) чистятся на клиенте, конспект читается ровно.
